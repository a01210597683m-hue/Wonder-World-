# WonderWorld Character Art Direction

## Approved decision
WonderWorld will support two distinct character art styles in the same game world. Do not force them into one unified style.

### 1. Semi-realistic characters
- Use the user's provided multi-character reference image as the primary visual reference.
- Preserve the reference's overall visual identity: facial features (eyes, nose, lips), skin texture, head/body proportions, and general rendering style.
- Include varied ages: children, teens, young adults, adults, and older adults.
- Include variety in skin tones, hairstyles, eye colors, outfits, and accessories.
- Avoid generic cartoon proportions, exaggerated or strange features, and an unwanted plastic-looking finish.
- Previous semi-realistic mockups were rejected by the user and must not be treated as approved.

### 2. Individual anime characters
- Preserve the distinct anime art style the user liked, with the provided individual black-outfit girl image as a reference.
- Keep anime characters visually distinct from the semi-realistic group; do not convert both styles into one.

## Implementation notes
- The user's original images are the primary visual references; generic generated examples are not substitutes for matching those references.
- Do not generate new images unless the user explicitly requests image creation.
- Images alone do not create playable characters. Prepare appropriate character assets/models and integrate them into the game for animation and interaction.
